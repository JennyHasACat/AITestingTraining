# M10 实战 Lab — 通用版：完整闭环 Capstone 演练

> **预计时长**：50 分钟 | **工具**：全套（Kimi + DeepSeek + GitHub Copilot）

---

## Capstone：30 分钟 AI 辅助测试闭环

### 选择你的场景

选择你当前实际工作中正在测试的一个功能（真实功能，效果最好），
或使用以下备选场景：

**备选场景**：
```
功能：用户邮箱验证
描述：用户注册后，系统发送验证邮件。
用户点击链接后邮箱验证成功，账号激活。
链接有效期 24 小时，过期后需要重新发送。
```

---

### Phase 1 — 需求分析（5 min）

发送给 Kimi：

```
[使用模板 R-01 + R-02]
```
