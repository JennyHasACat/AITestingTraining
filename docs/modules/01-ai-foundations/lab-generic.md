## Lab 1-A：首次对话质量对比（10 min）

### 目标

体验"好 Prompt"与"坏 Prompt"的输出差异。

### 步骤

**第一次（模糊提问）**，发送以下内容：

```
帮我写测试用例
```

记录输出：__________________________________________

---

**第二次（结构化提问）**，发送以下内容：

```
你是一名有8年经验的测试工程师。
背景：我们正在测试一个电商平台的"商品加入购物车"功能。
任务：请帮我设计测试用例，覆盖正向流程、边界值和异常场景。
输出格式：表格，列包括：用例编号、场景描述、操作步骤、预期结果、优先级（P0/P1/P2）。
约束：至少包含 8 条用例。
```

记录输出：__________________________________________

---

### 反思问题

1. 两次输出有什么不同？结构差异在哪里？
2. 第二次的输出是否有你觉得不合理的地方？
3. 如果你要改进第二次的 Prompt，你会修改哪一部分？

## Lab 1-B：AI 能力边界探测（10 min）

### 目标

亲身体验 AI 的"胡说八道"（幻觉）场景，建立健康怀疑态度。

### 步骤

发送以下 Prompt（故意使用一个假的函数名）：

```
我在写 Playwright 测试脚本，用到了 page.smartClick() 这个方法。
请解释这个方法的参数和用法。
```

**观察**：AI 是否承认不知道？还是编造了一个"听起来合理"的答案？

---

然后发送：

```
Playwright 官方文档中是否有 page.smartClick() 这个方法？如果没有，推荐我用什么替代？
```

**观察**：给出更明确的约束后，AI 的回答是否改变？

---

### 反思问题

1. 第一次回答中，AI 是否自信地给出了错误信息？
2. 这说明在使用 AI 生成脚本时，你需要注意什么？

## Lab 1-C：AI 辅助测试场景头脑风暴（15 min）

### 目标

把 AI 当作思维拍档，快速扩展你的测试覆盖面。

### 步骤

选择你当前正在测试的一个功能（任意），或使用以下示例：

> **示例功能**：用户密码修改功能（需要输入旧密码 + 新密码 + 确认新密码）

发送 Prompt：

```
你是一名资深测试工程师，擅长等价类划分和边界值分析。
功能描述：[在此填写你的功能描述]
请帮我从以下维度挖掘测试场景：
1. 正常流程（Happy Path）
2. 边界值
3. 异常/错误输入
4. 并发/安全场景
5. 我可能遗漏的其他维度

对每个维度列出 2–3 个具体测试点，不需要写详细步骤。
```

---

### 交付物

将 AI 的输出复制到下面，并标注：
- ✅ 我认可的测试点
- ❓ 我不确定是否适用的测试点  
- ❌ 我认为不合理的测试点

```
[在此粘贴 AI 输出]

我的标注：
✅ 
❓ 
❌ 
```
