## Lab 5-A：需求歧义识别（15 min）

以下是一段真实风格的需求描述，请用 AI（模板 R-01）分析问题：

```
功能需求：积分奖励系统

1. 用户每完成一笔订单可以获得积分
2. 积分可以在下次购物时使用，1积分=1元
3. 每次购物最多使用已有积分的50%
4. 积分有效期为获得后1年
5. 用户退款时，对应的积分需要扣除
6. VIP用户获得双倍积分
7. 积分余额不足时，系统应提示用户
```

### 你的补充（AI 可能遗漏的问题）：

提示：思考以下问题，AI 是否提到了？
- 积分是基于订单金额还是商品数量？比例是多少？
- "完成一笔订单"是指下单，还是确认收货？
- 部分退款时积分如何计算？
- 积分过期前有没有通知？
