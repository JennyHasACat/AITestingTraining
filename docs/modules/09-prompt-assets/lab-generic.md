## Lab 9-B：整理并提交你的第一条 Prompt（20 min）

### 步骤

1. 从 M1–M8 的学习中，选择一个你认为**最有价值的 Prompt**（使用效果最好的）

2. 按标准格式整理：

```markdown
## [你的模板编号] [你的模板名称]

**场景**：[一句话描述]
**推荐工具**：[Kimi / DeepSeek / 通义千问]
**效果评级**：⭐⭐⭐⭐
**贡献者**：[你的名字]
**最后验证日期**：2026-07-20
**已知局限**：[如有]

---

### Prompt 正文

[你的完整 Prompt，占位符用 [大括号] 标注]

---

### 使用说明

1. [如何使用]
2. [注意事项]

### 典型输出示例

[贴一个你使用时得到的好输出]

### 已知效果不佳的场景

[诚实记录 Prompt 的局限]
```

3. 将整理好的模板添加到项目的 `prompt-templates/` 中对应的分类文件

## Lab 9-C：为 Prompt 库设计使用规范（5 min）

请用 AI 辅助起草一段"团队 Prompt 使用规范"（100字以内），
要点：什么时候用 AI、什么时候不用、如何贡献新 Prompt。

发送给 AI：
```
我们是一个 10 人的软件测试团队，正在建立团队 AI 使用规范。
请帮我写一段简洁的规范说明（100字以内，中文），
包含：AI 辅助的适用场景、数据安全提醒、贡献 Prompt 的方式。
语气：专业但友好，不要太官僚。
```
