# 生成 emmx_to_md.py 的原始 Prompt

> 溯源档案：本文件原样保存生成 `emmx_to_md.py` 的完整 Prompt。后续迭代脚本时，拿着这份 Prompt 接着对话即可复现 / 扩展。

---

# 任务
写一个 Python 脚本 emmx_to_md.py，把亿图思维导图（mm.edrawsoft.cn）导出的
.txt 大纲文件，转换成 Xmind 可导入的 Markdown 大纲。

# 核心约束（最重要）
务必保留原文所有内容，一个字都不能丢。包括：多行节点续行、自带编号（如 1,）、
全角字符（如 ：）、双空格、SQL 语句、半全角混排等，一律原样保留。

# 输入格式（关键，必须读懂）
层级靠 Tab 缩进表示，每多一个 Tab = 深一层。但有一个陷阱：
**多行文本节点只有首行带 Tab 缩进，续行顶格无缩进**。

示例（注意第 2/3/4 行顶格，但它们其实是 Precondition 节点的续行）：
            Precondition
                1, holiday data has been configuration
2, Vietnam eployee with 'business unit = VM FRA'
3, employee type:  central staff
4, employee status: active/in probation

如果不识别这个陷阱，顶格续行会被误判成新根节点，层级全垮。

# 输出格式决策（已确定，不要改）
- 用 Markdown 列表 + 缩进表示层级（不要用标题 #，因为标题最多 6 层，本文件最深 8 层）
- 每层缩进 2 个空格
- 不加 H1 标题，纯列表输出
- 多行节点的续行合并进同一个列表项，行间用软换行（行尾两空格）连接
- 节点自带的编号（如 1,）原样保留为文本，不要转成 Markdown 的 1. 有序列表语法

# 续行判定规则（核心难点）
对每一行判定是否为"续行"（应合并回上一节点）：
- 当前行顶格（无 Tab 缩进）
- 且非文件首行
- 且当前栈顶节点有缩进（indent > 0）
- 且紧邻上一非空行（中间无空行打断）
→ 判为续行，合并到当前栈顶节点

特别注意连续多行续行的情况：如 Precondition 下 1,2,3,4 四行，
第 2 条续行的"上一行"是第 1 条续行（顶格 indent=0），但不能用
"上一行字面 indent" 来判，必须用"当前栈顶节点的 indent"。
否则第 2 条及之后的续行会被误判为孤立行/根节点。

另外处理"根节点多行续行"：当栈中仅有一个根节点（indent=0）且顶格行紧邻时，
也合并为该根的续行。

# 编码处理
自动嗅探编码，依次尝试：utf-8-sig（剥 BOM）→ utf-8 → gbk → gb18030 → latin-1 兜底。
如果解码出现替换字符 U+FFFD，要在报告里报警（防中文乱码静默通过）。
支持 --encoding 参数强制指定编码。

# 批量与 CLI
- 位置参数：输入可以是单个 txt 文件，或目录（目录模式递归找所有 *.txt）
- -o/--output：输出 md 路径（单文件）或输出目录（批量）；默认同名 md 放 txt 同目录
- 目录模式：输出 md 落在原 txt 所在目录，保持文件夹结构
- --dry-run：只解析、比对、出报告，不写任何 md
- --force：输出 md 已存在时强制覆盖（默认不覆盖，防冲掉手改产物）
- --strict：遇到顶格孤立行（可疑续行）直接抛错停机
- --report：报告输出路径，默认 convert_report.md
- --space-width：空格折算层级宽度，默认 4（仅当文件用空格而非 Tab 缩进时生效）

# 字符级保真比对（核心护栏，必须实现）
转换后，把原 txt 与产出的 md 做字符级比对，验证零丢字：
1. txt 全文去除所有空白字符（空格/Tab/换行）
2. md 全文去除列表符号 -、缩进空格、换行、软换行标记
3. 两者拼成纯字符序列，用 difflib.SequenceMatcher 算相似度
4. 100% 相似 = 零丢字；不一致时定位首个差异块，在报告里给出 txt 侧 vs md 侧文本片段

# 转换报告（convert_report.md）
包含：
- 摘要：处理文件数、成功/警告/失败/跳过、保真通过数
- 逐文件明细表：文件名 | 编码 | 节点数/续行合并数/孤立行数 | txt字符数 | md字符数 | 保真率 | 状态
- 警告详情：孤立行行号、续行合并行号、首个差异文本、U+FFFD 报警

# 统计指标（解析时记录）
每个文件记录：节点总数、续行合并数、顶格孤立行数（既非首行也非续行的顶格行）、
最大层级深度、空行数。孤立行按"保内容不丢"原则作为新根节点处理，但记入警告。

# 边界与健壮性
- 容忍 CRLF/LF/CR、文件末尾有无 trailing newline
- 容忍 Tab 与空格混用缩进（1 Tab = 1 单位，连续空格按 space-width 折算）
- 空文件/纯空行文件 → 跳过并记入报告，不产出空 md
- 零第三方依赖，只用 Python 标准库

# 验证要求
脚本写完后，用它转换一个真实样本文件，确认：
- 续行正确合并（如 Precondition 下 1,2,3,4 在同一列表项）
- 全角字符、双空格、符号原样保留
- 字符级保真率 100%
